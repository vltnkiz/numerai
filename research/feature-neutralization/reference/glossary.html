Glossary: Feature Neutralization

Terms used consistently across every lesson in this course. Print or bookmark this — it will keep growing.

Era
Numerai's unit of time in its dataset — roughly, a period during which market conditions are treated as consistent. Feature-target relationships can differ substantially from one era to the next.
Non-stationarity
The property that a statistical relationship (e.g. feature-to-target correlation) changes over time rather than staying fixed. The reason Numerai models can't just fit once and trust the fit forever.
Correlation (Pearson)
r = covariance(X, Y) / (std_dev(X) * std_dev(Y)) — a number from −1 to 1 summarizing how strongly two variables move together in a straight-line (linear) sense. Blind to relationships that curve. Covered in Lesson 2.
Monotonic relationship
A relationship that consistently increases (or consistently decreases) as the other variable increases — even if not at a constant rate, i.e. even if it curves. Weaker requirement than "linear."
Feature exposure
For a single feature: the Spearman rank correlation between a model's predictions and that feature's values. Measures how much the model's output moves in lockstep with that one feature.
Source: Model Diagnostics: Feature Exposure
Spearman rank correlation
Pearson correlation computed on the ranks of two variables rather than their raw values. Measures monotonic relationship strength without assuming linearity. Identical rank order gives +1; perfectly reversed rank order gives −1. Covered in Lesson 2.
Max feature exposure
max(abs(feature_exposures)) — the single largest feature exposure in absolute value. The "worst-case" concentration risk in a model.
RMS feature exposure
sqrt(mean(feature_exposures**2)) — an aggregate measure of overall reliance across all features, not just the single worst one.
Feature neutralization
A technique that reduces feature exposure by regressing predictions on a set of feature exposures and subtracting a proportion of the fitted (linear) component, leaving mostly the non-linear, interaction-driven signal. Covered in depth in Lesson 3.
Source: An Introduction to Feature Neutralization & Exposure
Proportion (neutralization parameter)
A 0–1 knob controlling how much of the linear, feature-driven component of a prediction gets subtracted during neutralization. 0 = no neutralization (original predictions). 1 = full neutralization (linear component fully removed). Covered in Lesson 3.
Matrix multiplication
Combining a matrix with a vector (or another matrix) by taking dot products: each output entry is the dot product of one row of the matrix with the vector. Xβ in the neutralization code is exactly this — each row's fitted value is that row's features dotted with the coefficient vector β. Covered in Lesson 6.
Source: 3Blue1Brown, "Matrix multiplication as composition"
Identity matrix
The matrix equivalent of the number 1 — square, with 1s on the diagonal and 0s elsewhere. Multiplying any vector or matrix by it leaves the value unchanged. Used to define the inverse. Covered in Lesson 6.
Inverse matrix
For a square matrix A, the matrix A⁻¹ such that A · A⁻¹ = I (the identity). Only exists for square matrices whose transformation doesn't collapse dimensions (non-zero determinant). Covered in Lesson 6.
Source: 3Blue1Brown, "Inverse matrices, column space and null space"
Moore-Penrose pseudo-inverse
A generalization of the matrix inverse (written pinv(X) or X⁺) that exists even when X isn't square — the normal case for a feature matrix, which has far more rows (stocks) than columns (features). Used to solve β = pinv(X) · prediction in feature neutralization. In practice, computed via np.linalg.lstsq rather than forming pinv(X) directly. Covered in Lessons 5 and 6.
