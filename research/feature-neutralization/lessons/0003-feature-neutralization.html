Lesson 3 of Feature Neutralization

Feature Neutralization

Lesson 1 taught you to measure how much a prediction leans on a feature. Lesson 2 taught you the tool that measures it. This lesson teaches the fix: how to actually remove that lean, on purpose, by a controlled amount.

Primary source: "An Introduction to Feature Neutralization & Exposure" — this lesson walks through the same procedure with a smaller, hand-computable example.

The idea: split predictions into "explained by the feature" and "leftover"

Take your model's predictions and one feature. Some part of the predictions can be written as a straight-line function of that feature — call this the fitted part. Whatever is left over — the part the feature can't explain — is the residual.

prediction = fitted (explained by the feature) + residual (everything else)

Feature exposure, from Lesson 1, measures how big the "fitted" part is relative to the whole. Neutralization's move is blunt and effective: throw away some or all of the fitted part, and keep the residual. Whatever was riding on the feature is gone; whatever the model knew independent of that feature survives.

Finding the "fitted" part: linear regression

How do you find the best straight-line explanation of the predictions using the feature? This is exactly what linear regression does: it finds the line fitted = β × feature that stays as close as possible to the actual predictions — specifically, the line that minimizes the total squared distance between the fitted values and the real predictions (this is why it's called least squares).

Geometrically, think of your predictions as an arrow (a vector) and the feature as a different arrow. Regression finds the point on the feature's arrow that sits closest to the tip of the predictions' arrow — that's a projection. The leftover gap between that closest point and the real prediction is the residual, and it always points in a direction perpendicular to the feature. That perpendicularity is precisely what "no more relationship left to explain" looks like.

With one feature, the best-fit slope has a simple formula you already have the pieces for from Lesson 2:

β = covariance(feature, prediction) / variance(feature)

With many features at once — the real Numerai case — the same idea holds, but solving for all the β's simultaneously (accounting for features that overlap with each other) requires a matrix tool called the Moore-Penrose pseudo-inverse. You don't need to hand-compute it; every linear algebra library has it in one call. What matters is that it's doing the same job as the formula above, just for many features that may be correlated with each other, all at once.

The proportion knob

Removing 100% of the fitted part is not always what you want — the feature may carry some real, useful signal alongside the risky over-reliance. Neutralization introduces a proportion parameter between 0 and 1 that controls how much of the fitted part to subtract:

neutralized = prediction − proportion × fitted
  • proportion = 0: subtract nothing — predictions unchanged, full feature exposure kept
  • proportion = 1: subtract the entire fitted part — feature exposure driven to (near) zero
  • 0 < proportion < 1: partially reduce exposure, trading away some correlation with the target in exchange for more robustness if that feature's relationship breaks down in a future era

This is the tradeoff your mission is really about: neutralizing too little leaves you exposed to regime change; neutralizing too much throws away real signal along with the risky part. There's no universally correct proportion — it's a judgment call you make by looking at exposure diagnostics, which is exactly what a later lesson will practice.

Worked example

Same five rows as Lesson 2's worked example. Prediction and one feature, plus the mean of each:

row: A B C D E mean prediction: 0.10 0.90 0.30 0.70 0.50 0.50 feature: 1 50 2 40 3 19.2

Step 1 — find β (slope) using the formula above. Numerically, for this data:

covariance(feature, prediction) ≈ 5.44 variance(feature) ≈ 454.2 β ≈ 5.44 / 454.2 ≈ 0.0120

Step 2 — compute the fitted value for row A (feature = 1), using fitted = mean(prediction) + β × (feature − mean(feature)):

fitted_A = 0.50 + 0.0120 × (1 − 19.2) = 0.50 + 0.0120 × (−18.2) ≈ 0.282

Step 3 — neutralize row A's prediction with proportion = 1 (full neutralization):

neutralized_A = prediction_A − 1 × fitted_A = 0.10 − 0.282 ≈ −0.182
Using the same row A (prediction_A = 0.10, fitted_A ≈ 0.282), what is neutralized_A if proportion = 0.5 instead of 1? (round to 3 decimals, e.g. 0.123)

With this, the full loop from Lesson 1 closes: measure exposure (Spearman), understand why it predicts fragility, and now — reduce it by a controlled amount via regression and a proportion knob.
