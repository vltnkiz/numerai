Lesson 5 of Feature Neutralization

From One Feature to All of Them

Lesson 3 gave you the algebra for one feature. Lesson 4 showed you the picture. This lesson closes the loop: the actual code Numerai's own tools use to neutralize predictions against an entire feature matrix at once.

Primary source: numerai-tools scoring.py — the neutralize function, from the official numerai-tools repository. Every line below is quoted verbatim from that file.

From a scalar β to a vector of β's

In Lesson 3, one feature meant one slope: β = covariance(feature, prediction) / variance(feature), a single number. With many features at once — the real situation, since a Numerai model has hundreds — you can't just repeat that formula feature-by-feature. Features are correlated with each other, so removing feature 1's fitted part can accidentally reintroduce exposure to feature 2. You need to solve for every β simultaneously, accounting for all those overlaps at once.

Stack the features as columns of a matrix X (rows = stocks/rows, columns = features) and the problem becomes: find the vector β that makes Xβ the closest possible match to the prediction vector, in the same least-squares sense as before. The closed-form answer is

β = pinv(X) · prediction

where pinv(X) is the Moore-Penrose pseudo-inverse — the matrix generalization of "divide by variance" that Lesson 3 flagged as coming later. It exists even when X isn't square or has correlated columns, which real feature matrices always do. fitted = Xβ is still the projection onto the space spanned by all the features together, and the residual is still perpendicular to all of them at once — not just each one individually, but the whole space they span. That's the multi-feature version of the perpendicularity fact from Lesson 4.

Reading the real function

In practice, nobody calls pinv directly — np.linalg.lstsq solves the same least-squares problem more numerically stably, without ever forming the pseudo-inverse matrix explicitly. Here's the actual function, with the parts to focus on called out below it:

def neutralize( df: pd.DataFrame, neutralizers: pd.DataFrame, proportion: float = 1.0, ) -> pd.DataFrame: df_arr = df.values neutralizer_arr = neutralizers.values neutralizer_arr = np.hstack( # add a column of 1s to the neutralizer array (neutralizer_arr, np.array([1] * len(neutralizer_arr)).reshape(-1, 1)) ) least_squares = np.linalg.lstsq(neutralizer_arr, df_arr, rcond=1e-6)[0] adjustments = proportion * neutralizer_arr.dot(least_squares) neutral = df_arr - adjustments return pd.DataFrame(neutral, index=df.index, columns=df.columns)
  • neutralizer_arr is X — one column per feature, one row per stock. df_arr is the prediction column(s) you're neutralizing.
  • the hstack of a column of 1s is doing the job that "mean-centering" did by hand in Lesson 3's fitted = mean(prediction) + β × (feature − mean(feature)) formula. Instead of centering the data first, the code gives the regression an intercept term (a constant feature that's always 1) and lets it absorb the mean itself. Same result, less bookkeeping.
  • np.linalg.lstsq(neutralizer_arr, df_arr, rcond=1e-6)[0] is the line doing the pseudo-inverse's job: it solves for every β at once. rcond=1e-6 is a numerical tolerance — it tells the solver to treat near-zero variance directions (e.g. two nearly-duplicate features) as noise rather than blowing up trying to divide by them.
  • adjustments = proportion * neutralizer_arr.dot(least_squares) is proportion × fitted from Lesson 3's formula — neutralizer_arr.dot(least_squares) is exactly Xβ, i.e. the fitted part, for every feature combined into one number per row.
  • neutral = df_arr - adjustments is prediction − proportion × fitted, unchanged from Lesson 3 — the only thing that got more complex was computing fitted.

That fitted row comes from one call to np.linalg.lstsq against both feature columns at once — not two separate single-feature regressions. Subtracting it at proportion = 1 drives the neutralized predictions' correlation with both feature 1 and feature 2 down to essentially zero in one step — no need to neutralize one feature, re-check, then neutralize the next.

This is the whole pipeline, end to end: get your model's predictions and your full feature matrix into two arrays, call neutralize(predictions_df, features_df, proportion), and every feature's exposure drops together — by exactly as much as your chosen proportion dictates.

If the jump from a single β to a whole vector of them feels too fast, ask your teaching agent to walk the two-feature worked example through by hand — showing how one regression's β₁ and β₂ come out different from what you'd get regressing on each feature alone, because each accounts for the other.
