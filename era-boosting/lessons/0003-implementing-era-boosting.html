Lesson 3 of Era Boosting

Implementing Era Boosting

Lesson 2 gave you the loop: build → score → keep worst → retrain → repeat. This lesson turns that loop into real XGBoost code, annotated line by line, so you can run it yourself.

Primary source: the code below is drawn directly from "Era Boosted Models" by richai — read the full post for the surrounding narrative and results.

The warm-start trick

One detail lesson 2's pseudocode glossed over: how do you "add trees to only the worst eras" without throwing away the trees you already built? XGBoost lets you hand a partially-built model back into .fit() and keep growing it:

model = XGBRegressor(max_depth=5, learning_rate=0.01, n_estimators=trees_per_step, colsample_bytree=0.1) model.fit(X, y) # round 1: trees 1..10, on ALL eras # ...score eras, select the worst proportion into worst_df... model.n_estimators += trees_per_step # now targeting 20 total booster = model.get_booster() model.fit(worst_df[features], worst_df["target"], xgb_model=booster)

xgb_model=booster is the whole trick: instead of training a fresh model, XGBoost keeps every tree already built and adds trees_per_step more on top, trained only on worst_df — the rows from this round's worst-performing eras. That's what makes it era boosting and not just "boosting, then filter" — the worst-era targeting happens inside the same growing ensemble, round after round.

max_depth=5, learning_rate=0.01, colsample_bytree=0.1 are richai's chosen defaults — small, slow-learning trees that sample only 10% of features each split. You don't need to derive why those particular values from XGBoost internals (out of scope here); just know they're deliberately conservative, because each round already narrows the training data to a worst-case subset, and aggressive trees on a narrow subset overfit fast.

Scoring each era

This is the "score every era separately" step from lesson 2, spelled out:

from scipy.stats import spearmanr era_scores = {} for era in df["era"].unique(): era_df = df[df["era"] == era] era_scores[era] = spearmanr(era_df["pred"], era_df["target"])[0]

era_scores ends up as one correlation number per era — exactly the Corr row from lesson 2's 6-era walkthrough. Sorting this dict and keeping the bottom proportion of eras is what produces worst_df above.

Measuring the before/after Sharpe

Once you have era_scores for a model (before or after era boosting), the same three lines give you the numbers to compare:

print(np.mean(era_scores.values())) # mean correlation print(np.mean(era_scores.values()) / np.std(era_scores.values())) # plain Sharpe print(smart_sharpe(era_scores.values())) # autocorrelation-penalized Sharpe

To see the effect era boosting has, run this scoring block twice: once on a model trained the ordinary way (a single model.fit(X, y) with no worst-era loop), and once on the era-boosted model above. The gap between the two Sharpe numbers is the result you're trying to reproduce — richai's post reports 2.28 → 21.99 in-sample. Your numbers won't match exactly (different data, different era count), but the direction — plain Sharpe well below era-boosted Sharpe — is the thing to confirm.

Remember the caveat from lesson 2: whatever Sharpe gap you measure this way is in-sample. It tells you era boosting is doing what it claims on the training data — it does not by itself tell you the gain survives on validation eras the model never trained on. Treat a big in-sample gap as "the mechanism is working," not yet as "this will help my live model."

Putting the full loop together

def era_boost_train(X, y, era_col, proportion=0.5, trees_per_step=10, num_iters=200): model = XGBRegressor(max_depth=5, learning_rate=0.01, n_estimators=trees_per_step, colsample_bytree=0.1) model.fit(X, y) new_df = X.copy() new_df["target"] = y new_df["era"] = era_col for i in range(num_iters): new_df["pred"] = model.predict(X) era_scores = {} for era in new_df["era"].unique(): era_df = new_df[new_df["era"] == era] era_scores[era] = spearmanr(era_df["pred"], era_df["target"])[0] worst_eras = sorted(era_scores, key=era_scores.get)[:int(len(era_scores) * proportion)] worst_df = new_df[new_df["era"].isin(worst_eras)] model.n_estimators += trees_per_step booster = model.get_booster() model.fit(worst_df.drop(columns=["target", "era", "pred"]), worst_df["target"], xgb_model=booster) return model, era_scores

Every piece here is one of lesson 2's four steps, now with a concrete line of code behind it: build (model.fit), score (the spearmanr loop), keep worst (sorted(...)[:cutoff]), retrain (model.fit(worst_df..., xgb_model=booster)).
