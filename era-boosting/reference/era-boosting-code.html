Code Reference: Era Boosting

The full annotated implementation from lesson 3. Print or bookmark this — it's the thing to copy from when you're building this for real.

Source: adapted from "Era Boosted Models" by richai on the Numerai forum.

The training loop

from scipy.stats import spearmanr from xgboost import XGBRegressor import numpy as np def era_boost_train(X, y, era_col, proportion=0.5, trees_per_step=10, num_iters=200): model = XGBRegressor(max_depth=5, learning_rate=0.01, n_estimators=trees_per_step, colsample_bytree=0.1) model.fit(X, y) new_df = X.copy() new_df["target"] = y new_df["era"] = era_col for i in range(num_iters): new_df["pred"] = model.predict(X) era_scores = {} for era in new_df["era"].unique(): era_df = new_df[new_df["era"] == era] era_scores[era] = spearmanr(era_df["pred"], era_df["target"])[0] worst_eras = sorted(era_scores, key=era_scores.get)[:int(len(era_scores) * proportion)] worst_df = new_df[new_df["era"].isin(worst_eras)] model.n_estimators += trees_per_step booster = model.get_booster() model.fit(worst_df.drop(columns=["target", "era", "pred"]), worst_df["target"], xgb_model=booster) return model, era_scores

Scoring before/after Sharpe

scores = list(era_scores.values()) print(np.mean(scores)) # mean correlation print(np.mean(scores) / np.std(scores)) # plain Sharpe print(smart_sharpe(scores)) # autocorrelation-penalized Sharpe

Run the plain-Sharpe line on a model trained with a single model.fit(X, y) (no worst-era loop), and again on era_boost_train's output, to reproduce the before/after comparison.
